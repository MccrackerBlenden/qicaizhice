# 企财智策 | Qicaizhice

**从财务数据到经营判断。**

企财智策是一个**个人独立开发、以本地运行为主的财务分析与决策辅助项目**。它围绕企业财务数据的获取、核验、分析、研究和报告输出，设计了一套可交互的工作台。项目包含独立设计的产品首页、三张财务报表的三维视觉叙事，以及可在本地启动的完整应用逻辑。

## 功能概览

- **导入与检查**：读取年度及部分月度、季度财务报表，处理字段映射、单位、期间与三表勾稽问题。
- **财务工作台**：财务指标、跨期比较、诊断观察、财务变化分析与可追溯的计算依据。
- **情景与研究**：基于合成数据的评分、敏感性、候选方案比较与受约束的静态情景试算；部分研究仅支持指定的合成企业和年度。
- **证据与报告**：提供来源记录、人工核对、部分公开披露资料辅助核验，以及 PDF、Excel 或网页报告输出。
- **项目保存**：在用户自己的计算机上管理分析项目与历史快照。

## 数据说明

仓库内的 **328 家企业、财务报表、评价数据、优化候选方案和教学上传样例均为虚构或合成内容**，仅用于演示程序功能与检验计算流程。它们不代表任何真实企业、真实行业分布或实际经营结果，也不能用于推断具体公司的信用、财务风险或未来表现。

**用户自有数据和内置合成示例是两条独立处理路径。** 导入真实数据不会自动得到合成企业的样本排名、状态分类、研究评分或演示优化方案。财务来源的真实性需要使用者另行核验。

## 在本地运行

推荐 Windows 11，Node.js 22.13+；部分 Python 计算与报告功能需要 Python 3.10+ 及对应的可选依赖。建议使用较新的 Chrome 或 Edge。

1. 克隆或下载仓库，将文件完整保存在本机文件夹。
2. Windows 双击 `启动体验版.bat`；或在项目根目录执行 `node server.mjs`。
3. 在浏览器打开终端显示的地址，通常为 `http://127.0.0.1:8791/`。
4. 首次使用建议从合成示范案例开始，再进入工作台尝试 `sample_uploads/` 中的教学样例。
5. 关闭终端中的服务，或运行 `停止体验版.bat`。

如端口被占用，本地服务会尝试 8792—8800，请以实际终端地址为准。

没有安装 Node.js 的 Windows x64 用户可选择 `启动_独立环境版.bat`：该可选启动方式**首次需要联网下载运行时**，并尝试校验文件哈希。此方式尚未完成本次交付的 Windows 实机验证；如果遇到问题，建议安装官方 Node.js 并使用上述普通入口。

基本的网页与 Node.js 服务无需执行 `npm install`。部分 PDF、Excel 和计算能力使用 Python，本机可能需要安装 `openpyxl`、`reportlab` 等依赖；`pypdf` 已随项目包含。缺少可选依赖会影响相应功能。

## 技术组成

| 部分 | 技术方案 |
|---|---|
| Web 应用 | HTML、CSS、JavaScript |
| 首页动态效果 | Three.js、GSAP / ScrollTrigger、WebGL 降级显示 |
| 本地 HTTP 服务 | Node.js，附 Python 后备入口 |
| 数据分析与模型 | Python、财务指标计算、情景模拟与有限网格优化 |
| 持久化 | 本地 SQLite |
| 报告 | HTML、PDF、Excel |

## 使用边界和隐私

- 当前面向**本地单用户**使用和功能演示，不提供公有云多租户账号体系，不宣称已经完成商业安全认证或独立财务审计。
- 服务默认只监听本机 `127.0.0.1`。用户主动保存的项目数据写入本机用户数据目录，不应加入 Git 仓库。
- 财务上传在本地解析；公开披露检索等由用户主动触发的联网功能可能请求相关第三方公开网站。运行前请检查所使用的数据是否适合在本机处理。
- 模型输出只在相应的数据、参数和约束范围内成立；**不构成投资建议、信用评级、审计意见或实际经营决策的替代品**。
- GitHub 仓库用于源代码展示与分发。它**不是**一个在线业务服务，GitHub Pages 也无法单独运行本地 Python/SQLite 接口。
